ملفات موقع حكاية | HIKAYA
نسخة ٢ نوفمبر ٢٠٢٦

المستودع: https://github.com/ainoamn/hikaya
النشر: Vercel (outputDirectory = dist)

المحتويات:
- dist: ملفات الموقع الجاهزة للنشر، وتشمل HTML وCSS وJavaScript والصور والخطوط.
- artwork-source: النسخ الأصلية للرسوم الجديدة.
- docs: التوثيق الكامل وملفات النشر ووجوه الأبناء.
- scripts: بوابة البناء والتحقق قبل Vercel.
- tests: اختبارات المحتوى والصيغ والقراءة.
- server.mjs: خادم المعاينة المحلية، دون تثبيت حزم إضافية.
- package.json و vercel.json: أوامر التشغيل وإعداد الاستضافة.
- README.md وBRAND.md: توثيق المشروع والشعار.

التشغيل المحلي:
1. ثبّت Node.js 18 أو أحدث إذا لم يكن موجودًا.
2. افتح نافذة Terminal داخل مجلد hikaya.
3. نفّذ: npm run verify
4. نفّذ: npm start
5. افتح: http://localhost:4318
6. للإيقاف اضغط Ctrl+C.

الرفع على GitHub ثم Vercel:
1. ادفع الفرع main إلى https://github.com/ainoamn/hikaya
2. في Vercel استورد المستودع.
3. Build Command: npm run build
4. Output Directory: dist
راجع docs/DEPLOY-VERCEL.md و docs/DOCUMENTATION.md للتفاصيل.

الحالة الحالية:
الموقع نسخة واجهة تفاعلية؛ الدفع والطباعة والشحن وتوليد الصور والفيديو عبر خدمات خارجية غير مفعّلة.
الرسوم مُعدّة مسبقًا. تصدير 8K يحدد أبعاد الملف، ولا يجعل مصادر الرسوم 8K أصلية.
القراءة الصوتية تستخدم الأصوات المتاحة على الجهاز، والفيديو القابل للتنزيل صامت.
القصص المحفوظة في مكتبة المتصفح ليست جزءًا من ملفات الموقع ولا تنتقل تلقائيًا إلى جهاز آخر.
لم تُضمّن الصور الفوتوغرافية الأصلية أو مفاتيح خدمات أو بيانات دفع في الحزمة.
