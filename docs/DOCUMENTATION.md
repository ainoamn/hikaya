## ١) ما هو المشروع؟

**حكاية** موقع تفاعلي لقصص الأطفال بالعربية والإنجليزية، بهوية عُمانية وخليجية وعربية.  
الطفل يصبح بطل القصة، مع مكتبة قصص، استوديو كتاب مصوّر، معاينة كتيّب متحركة، قراءة صوتية، وتصدير PDF/صور/HTML.

الحالة الحالية: **واجهة تجريبية كاملة على الواجهة الأمامية**.  
الدفع والطباعة التجارية وتوليد الصور/الفيديو عبر خدمات خارجية **غير مفعّلة** بعد.

## ٥) تخصيص وجوه الأبناء

الطلب الأصلي: جعل وجوه الشخصيات الكرتونية مطابقة لوجوه الأبناء الثلاثة، مع الحفاظ على الطابع العُماني.

### ما تم تنفيذه

1. استُخدمت صور عائلية مرجعية عبر أداة توليد/تحرير الصور.
2. أُنتجت رسوم كرتونية تقريبية (ليست مطابقة فوتوغرافية).
3. الصور الفوتوغرافية الأصلية **غير مضمّنة** في المستودع ولا تُنشر.

### توزيع الملامح

| الابن/الابنة في الصورة المرجعية | الأدوار الكرتونية |
| --- | --- |
| الولد الأطول يسارًا | الولد العُماني، الولد الخليجي، الفارس |
| البنت في الوسط | الأدوار الأنثوية (فتاة عُمانية، فارسة، رائدة فضاء، غوّاصة…) |
| الولد الأصغر يمينًا | البحّار، البطل العُماني الخارق في الواجهة |

### الملفات النشطة

- `dist/assets/characters-family.png`
- `dist/assets/hero-family.png`
- `dist/assets/worlds-family.png`
- التفاصيل الكاملة للتوليد: `family-art-prompts.md`

### حدود مهمة

- التشابه كرتوني تقريبي.
- رفع صورة جديدة من المستخدم **لا يعيد توليد الوجوه تلقائيًا** في هذه النسخة.
- الموقع ما زال نموذجًا خاصًا؛ خدمة الذكاء الاصطناعي الحية غير مفعّلة.

## ٦) تجربة الكتاب المصوّر

- كل صفحة مشهد مستقل؛ النص مرسوم **داخل** الصورة بخلفية شفافة.
- معاينة متحركة للكتيّب (غلاف + تقليب صفحات).
- تصدير حتى **8192×8192** (حجم إخراج، وليس بالضرورة دقة مصدر الرسم).
- بعض الرسوم الأصلية منخفضة الدقة؛ التكبير لا يضيف تفاصيل مفقودة.

## ٧) المكتبات والتبعيات

المشروع **لا يحتاج npm packages للتشغيل**.

| الحاجة | المصدر |
| --- | --- |
| وقت التشغيل | متصفح حديث + Node.js ≥ 18 للمعاينة المحلية/البناء |
| خط الواجهة | Google Fonts: DM Sans + Noto Sans Arabic |
| خط التصدير | `dist/assets/NotoSansArabic.ttf` محليًا |
| الصوت | Web Speech API من الجهاز |
| PDF/ZIP | مكتوب محليًا في `book.js` بدون مكتبات خارجية |

أوامر التحقق:

```bash
npm run verify
npm test
npm start
```

ثم افتح: http://localhost:4318

## ٨) النشر على GitHub ثم Vercel

### GitHub

```bash
git init
git add .
git commit -m "Initial Hikaya site ready for Vercel"
git branch -M main
git remote add origin https://github.com/ainoamn/hikaya.git
git push -u origin main
```

### Vercel

1. ادخل إلى https://vercel.com/new
2. استورد المستودع `ainoamn/hikaya`
3. اترك الإعدادات كما في `vercel.json`:
   - Framework: Other / null
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Deploy

أو عبر CLI:

```bash
npx vercel --prod
```

بعد الربط، أي `git push` إلى `main` ينشر تلقائيًا.

## ١٠) الخصوصية والأمان في النسخة الحالية

- لا تُرسل صور الطفل إلى خادم.
- لا تُجمع مفاتيح دفع أو أسرار في المشروع.
- العناوين في نموذج الطلب تبقى في ذاكرة المتصفح فقط.
- مكتبة القصص المحفوظة محلية على الجهاز ولا تنتقل تلقائيًا.
