# المرحلة 2 — التخصيص البصري (وجوه ومشاهد)

مرجع اختيار المزوّدين والتفعيل المرحلي: [`../AI-SERVICES-PLAN.md`](../AI-SERVICES-PLAN.md)

## الهدف
تحويل صورة الطفل إلى شخصية كرتونية متسقة عبر صفحات الكتاب.

## النواقص الحالية
- الوجوه مُعدّة مسبقًا لعائلة واحدة فقط
- رفع صورة جديدة لا يغيّر الرسوم
- بعض الأصول منخفضة الدقة رغم تصدير 8K

## خط الأنابيب
1. موافقة أهلية → رفع صورة
2. Job: `character_base` (وجه/شعر/لون بشرة بأسلوب حكاية)
3. Job: `scene_pages[]` لكل صفحة مع ثبات الهوية
4. معاينة أهلية → اعتماد أو إعادة توليد
5. تخزين الأصول النهائية للطلب

## عقود
- `POST /api/ai/jobs` body: `{type, childId, storyId, pageIndexes?}`
- `GET /api/ai/jobs/:id`
- Webhook داخلي عند اكتمال المهمة

## معايير الجودة
- تشابه كرتوني مقبول في اختبار أهلي ≥ 8/10
- مصدر صفحة للطباعة بدقة أصلية كافية (مستهدف ≥ 4K) وليس تكبيرًا فارغًا
- لا لصق فوتوغرافي مباشر على وجه الطفل في المنتج النهائي

## ملاحظة خصوصية
الصور المرجعية تُحذف أو تُقيَّد زمنيًا بعد اعتماد الشخصية حسب السياسة المنشورة.
