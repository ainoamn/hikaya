# المرحلة 5 — التجارة والدفع

## الهدف
أول إيراد حقيقي عبر بيع رقمي آمن.

## النواقص الحالية
- نموذج طلب تجريبي بلا تحصيل
- الأسعار في الواجهة توضيحية

## المطلوب
1. كتالوج منتجات خادمي: digital / print / video / bundle
2. Checkout مستضاف (Stripe أو بوابة خليجية)
3. Webhooks موقّعة + idempotency
4. إنشاء Order فقط بعد `payment_confirmed`
5. تسليم رقمي تلقائي (رابط موقّت)
6. إيصالات بريدية

## عقود
- `POST /api/checkout/session`
- `POST /api/webhooks/payments`
- `GET /api/orders/:id`

## معايير القبول
لا يُسلَّم ملف قبل تأكيد الدفع؛ إعادة webhook لا تكرر التسليم؛ التلاعب بسعر العميل لا يغيّر الفاتورة.
