# المرحلة 6 — الطباعة والشحن

## الهدف
كتاب يصل إلى الباب مع تتبع.

## المطلوب
1. محوّل شريك طباعة (API أو بريد طلب منظم)
2. حساب شحن حسب الدولة والوزن
3. حالات: paid → in_production → shipped → delivered / failed
4. سياسات تأخير وتالف وإعادة طباعة
5. دعم دول الخليج أولًا ثم توسيع

## معايير القبول
طلب تجريبي كامل من الدفع حتى رقم التتبع؛ تسعير الشحن من الخادم فقط.
