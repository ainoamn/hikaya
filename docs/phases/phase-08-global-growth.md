# المرحلة 8 — العالمية والنمو

## الهدف
توسعة السوق والأداء والاكتشاف مع بقاء الهوية العُمانية جوهرًا.

## المطلوب
1. عملات متعددة وحساب ضرائب حسب الدولة
2. SEO عربي/إنجليزي وصفحات هبوط موسمية
3. أداء الصور (AVIF/WebP، أحجام متجاوبة)
4. PWA لاحقًا
5. قنوات B2B: مدارس وهدايا شركات
6. برنامج إحالة/هدايا

## معايير القبول
تحويل مقبول من زيارة عضوية؛ زمن تحميل مقبول على جوال خليجي متوسط؛ دعم لغة وواجهة دون كسر RTL.
