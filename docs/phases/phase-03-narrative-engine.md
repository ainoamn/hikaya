# المرحلة 3 — محرك السرد والمحتوى

## الهدف
سرد أكثر تشويقًا، قوالب آمنة للأطفال، وتوليد مقيَّد + إدارة محتوى.

## الموجود
- ٤٢ قصة يدوية + تكيّف جندري في `gender-stories.js`
- قراءات تاريخية مفصولة بمصادر

## المطلوب
1. CMS داخلي لتحرير القصص دون تعديل ملفات يدويًا
2. قالب سرد إلزامي: بداية → حوار → لغز/عقدة → حل → قيمة
3. مولّد AI يستخدم القالب + اهتمامات الطفل + فلتر عمر
4. قاموس أسماء عربية ونطق
5. مسارات اهتمام: مهن، عائلة، بحر، فضاء، خيل، إطفاء…

## معايير القبول
لا تسرّب رموز جندر `{}[]`؛ لا خلط حقائق تاريخية بمؤامرات خيالية دون تمييز؛ قصة مولَّدة تمر على فلتر سلامة قبل المعاينة.
