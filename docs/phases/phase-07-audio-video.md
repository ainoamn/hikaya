# المرحلة 7 — الصوت والفيديو

مرجع TTS والفيديو المرحلي: [`../AI-SERVICES-PLAN.md`](../AI-SERVICES-PLAN.md)

## الهدف
تجربة سينمائية: تقليب صفحات + تعليق صوتي عربي عالي الجودة.

## الموجود
- `book-cinema.js` معاينة صامتة + WebM محلي
- `story-voice.js` يعتمد أصوات الجهاز

## المطلوب
1. TTS عربي عصبي مستضاف + نطق أسماء مخصّص
2. دمج الصوت في فيديو الصفحات
3. طابور توليد MP4 وتسليمه بعد الدفع
4. احترام `prefers-reduced-motion`

## معايير القبول
فيديو منسّل يتطابق نصه مع صفحات القصة؛ لا سقوط إلى صوت إنجليزي لنص عربي.
