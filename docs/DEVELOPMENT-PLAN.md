## ٢) خريطة الحالة: موجود × ناقص

### ٢.١ ما يعمل اليوم

- موقع ثابت ثنائي اللغة على https://hikaya-nine.vercel.app
- ٤٢ قصة + تكيّف جندري + ٥ قراءات تاريخية
- استوديو كتاب، نص داخل الصورة، تصدير PDF/PNG/ZIP/HTML
- معاينة كتيّب متحركة وتسجيل WebM صامت محليًا
- قراءة صوتية عبر Web Speech API للجهاز
- رسوم عائلية مُعدّة مسبقًا لثلاثة أبناء (تقريب كرتوني)
- شعار وهوية ووثائق تشغيل/نشر

## ٣) خطة التطوير على مراحل

### المرحلة 0 — تثبيت الأساس (١–٢ أسابيع) ✅ جزئيًا منجز

**الهدف:** مستودع نظيف، نشر مستقر، وثائق واضحة.

- [x] نشر GitHub + Vercel
- [x] بوابة `build`/`verify`
- [x] توثيق الفكرة والخطة
- [ ] ربط نطاق مخصص (مثل `hikaya.om` / `hikaya.app`)
- [ ] مراقبة أخطاء أساسية (Sentry أو ما يعادله)
- [ ] صفحة حالة/إصدار واضحة «نسخة تجريبية»

**مخرجات:** منصة مستقرة للتطوير فوقها.

---

### المرحلة 1 — منصة الحسابات والبيانات (٣–٥ أسابيع)

**الهدف:** قصص وملفات المستخدم لا تختفي مع المتصفح.

1. تصميم نموذج البيانات: User, ChildProfile, Story, Page, Asset, Order, Consent
2. Auth + ملفات أطفال متعددة لكل حساب
3. تخزين سحابي مشفّر للصور المرجعية مع حذف مجدول
4. مزامنة المكتبة بدل `localStorage`
5. سجل موافقة ولي الأمر وإمكانية تصدير/حذف البيانات

**نواقص تُغلق:** الحسابات، السحابة، دورة حياة الصورة، أساس الطلبات.

---

### المرحلة 2 — محرك التخصيص البصري (٤–٨ أسابيع)

**الهدف:** وجه الطفل يظهر بصدق كرتوني عبر الصفحات.

1. خط أنابيب: رفع صورة → موافقة → توليد شخصية أساسية → توليد مشاهد
2. الحفاظ على الهوية عبر المشاهد (وجه ثابت، أزياء/بيئة متغيرة)
3. قائمة انتظار مهام + حالات: queued / processing / ready / failed
4. معاينة قبل الاعتماد النهائي للأهل
5. معايير جودة: دقة مصدر كافية للطباعة (مستهدف أصلي ≥ 4K للصفحة، لا تكبير فارغ)
6. استبدال الأصول المنخفضة الحالية تدريجيًا

**نواقص تُغلق:** الوجوه الحية، المشاهد حسب القصة، جودة الطباعة البصرية.

---

### المرحلة 3 — محرك السرد والمحتوى (٣–٦ أسابيع بالتوازي مع 2)

**الهدف:** قصص أكثر تشويقًا، مترابطة، قابلة للتوليد بأمان.

1. محرّر محتوى داخلي للقصص اليدوية (المصدر الحالي لـ ٤٢ قصة)
2. قوالب سرد: بداية → عقدة → حوار → لغز → حل → قيمة
3. توليد AI مقيَّد بالقوالب + فلتر عمر ولغة
4. تحسين التكيّف الجندري والأسماء العربية
5. مسارات اهتمامات: مهن، عائلة، بحر، فضاء، خيل… كمولّدات متخصصة
6. فصل صارم بين الخيال والتاريخ الموثّق

**نواقص تُغلق:** محدودية التوسع اليدوي، جودة السرد المتفاوتة، إدارة المحتوى.

---

### المرحلة 4 — الكتاب الرقمي الاحترافي (٢–٤ أسابيع)

**الهدف:** ملف جاهز للمراجعة والطباعة بقدر الإمكان.

1. توحيد مقاس الصفحة، الهوامش، bleed، اتجاه RTL/LTR في PDF
2. ملفات فصل ألوان/ICC حسب متطلبات المطبعة
3. ضمان أن النص داخل الرسم بمقروئية عالية دون قصّ
4. حزم تصدير: إثبات RGB للأهل + حزمة مطبعة منفصلة
5. اختبارات آلية لعدد الصفحات وتفرّد الصور

**نواقص تُغلق:** فجوة «تصدير جميل» مقابل «ملف مطبعة معتمد».

---

### المرحلة 5 — التجارة والدفع (٣–٥ أسابيع)

**الهدف:** أول إيراد حقيقي بأمان.

1. خطط منتجات حقيقية في الخادم (رقمي/مطبوع/فيديو/حزمة)
2. Checkout مستضاف + تحقق webhook + منع تكرار المعالجة
3. إنشاء الطلب فقط بعد تأكيد الدفع
4. إيصالات بريدية وفواتير
5. لوحة طلبات للدعم

**نواقص تُغلق:** الدفع الوهمي، التسعير على العميل، غياب سجل الطلبات.

---

### المرحلة 6 — الطباعة والشحن (٤–٧ أسابيع)

**الهدف:** الكتاب يصل إلى الباب.

1. اختيار شريك طباعة (محلي عُمان/خليج أو طباعة عند الطلب دولية)
2. قوالب غلاف/متن/spine حسب عدد الصفحات
3. تسعير شحن حسب الدولة والوزن
4. حالات: paid → in_production → shipped → delivered
5. سياسة تأخير/تالف/إعادة طباعة

**نواقص تُغلق:** وعد الطباعة غير المنفَّذ.

---

### المرحلة 7 — الصوت والفيديو (٣–٦ أسابيع)

**الهدف:** تجربة سينمائية حقيقية.

1. TTS عربي عصبي عالي الجودة مع ضبط أسماء الأطفال
2. دمج الصوت في فيديو تقليب الصفحات
3. اختياري: مشاهد حركة قصيرة مولَّدة
4. تنزيل MP4 جاهز للأهل
5. احترام تقليل الحركة وإمكانية إيقاف الصوت

**نواقص تُغلق:** اعتماد صوت الجهاز، الفيديو الصامت، وعد «الحكاية السينمائية».

---

### المرحلة 8 — العالمية والنمو (مستمر بعد الإطلاق المحدود)

**الهدف:** منصة تليق بجمهور خارج البلد الواحد.

1. نطاق ودعم عملات متعددة (OMR/AED/SAR/USD)
2. تحسين SEO عربي/إنجليزي وصفحات قصص قابلة للمشاركة بحذر خصوصي
3. أداء: CDN، صور AVIF/WebP، تقسيم الحزم إن انتقلنا لإطار حديث
4. برنامج هدايا ومواسم (رمضان، العودة للمدارس، العيد)
5. قنوات مدارس وشركاء محتوى
6. تطبيق PWA أو غلاف جوال لاحقًا

## ١٠) الخلاصة

حكاية تمتلك اليوم **فكرة واضحة، علامة، محتوى غني، وتجربة واجهة مقنعة**.  
النواقص ليست تجميلية: إنها طبقة المنتج الحقيقي — **هوية بصرية حية، خلفية، دفع، طباعة، صوت/فيديو، وامتثال**.

المسار الأذكى:  
**ثبّت الثقة والجودة على قصة رقمية ممتازة → ثم الطباعة → ثم السينما → ثم التوسع العالمي.**
